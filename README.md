# Саркастичный Telegram-бот

Бот на Python (только стандартная библиотека), который отвечает на любое сообщение сарказмом и никогда не отвечает прямо на вопрос. Если собеседник злится или прощается, бот становится милым и уговаривает остаться. Ответы генерирует Google Gemini.

## Запуск

1. Создайте бота в [@BotFather](https://t.me/BotFather) и получите токен.
2. Получите ключ Gemini API в [Google AI Studio](https://aistudio.google.com/).
3. Скопируйте `.env.example` в `.env` и заполните:

   ```
   BOT_TOKEN=токен_от_BotFather
   GEMINI_API_KEY=ключ_gemini
   ```

   Файл `.env` исключён из git, не коммитьте его.
4. Запустите (нужен Python 3.9+):

   ```bash
   python3 bot.py
   ```

Одновременно должен работать только один экземпляр бота, иначе Telegram вернёт `409 Conflict`.

## Настройка

- `GEMINI_MODEL` в `.env` — список моделей через запятую, которые бот пробует по порядку.
- Тон и правила ответов задаются в `SYSTEM_PROMPT` в `bot.py`.
- Сообщения, пришедшие, пока бот был офлайн, игнорируются.
